# W04 · Python 面向对象 🐱🐶🐭

> 函数让你"复用一段逻辑"，而**类**让你"复用一个**有状态的概念**"。
> 这一周你会从"操作数据"，升级成"操作**对象**"。

---

## 1. 为什么要 OOP？🤔

**类比**：
- **过程式编程**：你像厨子，挨个处理食材。
- **OOP**：你管理一群"角色" — 每个角色（对象）有自己的**属性**（性格、技能）和**行为**（方法）。

想象你要写一个宠物乐园：
- 没有 OOP：每只宠物的属性散落在一堆变量里，方法也各自为政。
- 用 OOP：定义一个 `Pet` 类，每只小猫小狗都从这个"模板"造出来，统一管理。

> 💡 **类（class）** = 模板（饼干模具），**实例（instance）** = 用模板生产的东西（饼干）。

## 2. 第一个类：定义、`self`、`__init__` 🐾

```python
class Pet:
    def __init__(self, name, age):     # 构造方法（造饼干时填模具）
        self.name = name               # self = 当前实例
        self.age = age

    def bark(self):                    # 实例方法
        print(f"{self.name} 在叫！")

dog = Pet("旺财", 3)                    # 调用 __init__
dog.bark()                             # 旺财 在叫！
print(dog.name, dog.age)               # 旺财 3
```

**逐行**：
- `class Pet:` 定义一个名为 Pet 的类。约定**首字母大写**。
- `__init__` 是**初始化方法**，对象一造出来就调用，给它"装属性"。
- `self` 永远是第一个参数，代表"我自己这个实例"。
- `dog = Pet("旺财", 3)` 实例化（不需要写 `new`）。

写一个 `Circle` 类，属性 `radius`，方法 `area()` 返回面积。

import math

## 3. 三种方法：实例 / 类 / 静态 ⚙️

```python
class Counter:
    total = 0                              # 类属性（所有实例共享）

    def __init__(self):
        self.value = 0                     # 实例属性

    def incr(self):                        # 实例方法
        self.value += 1
        Counter.total += 1

    @classmethod
    def stats(cls):                        # 类方法（cls = 类本身）
        print(f"总共 {cls.total} 次")

    @staticmethod
    def help():                            # 静态方法（没有 self / cls）
        print("Counter 用法：c.incr()")

a = Counter(); a.incr(); a.incr()
b = Counter(); b.incr()
Counter.stats()      # 总共 3 次
Counter.help()
```

| 方法 | 第一个参数 | 何时用 |
|------|-----------|--------|
| 实例方法 | `self` | 操作单个实例 |
| 类方法 | `cls` | 操作类本身（如工厂方法） |
| 静态方法 | 无 | 工具函数，逻辑上属于类 |

## 4. 公有 / 私有：下划线约定 🔒

```python
class Account:
    def __init__(self, owner, balance):
        self.owner = owner          # 公有
        self._secret = "内部用"      # 单下划线：约定"别动我"
        self.__pin = "1234"         # 双下划线：名称改写

a = Account("李雷", 100)
print(a.owner)              # 李雷
print(a._secret)            # 仍然能访问，只是约定
# print(a.__pin)            # ❌ AttributeError
print(a._Account__pin)      # 1234（双下划线被改成 _类名__name）
```

> 💡 Python **没有真正的私有** — 只有"君子协定"。`_` 表示"内部"，`__` 表示"我真的不想让你碰"。

  ## 5. 继承：is-a 关系        

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def eat(self):
        print(f"{self.name} 在吃饭")

class Dog(Animal):                           # Dog "是一种" Animal
    def __init__(self, name, breed):
        super().__init__(name)               # 调用父类 __init__
        self.breed = breed  
    def bark(self):
        print(f"{self.name}（{self.breed}）汪汪汪")

d = Dog("旺财", "柴犬")
d.eat()      # 旺财 在吃饭     ← 继承来的
d.bark()     # 旺财（柴犬）汪汪汪
```

> 💡 `super()` 是"找父类"的快捷方式，避免硬编码父类名。

## 6. 多继承与 MRO 🪜

**问题**：如果一个类继承了两个父类，调用方法该走哪条路？答：按 **MRO（方法解析顺序）**，由 **C3 算法** 决定。

```python
class A:
    def hi(self): print("A")
class B(A):
    def hi(self): print("B")
class C(A):
    def hi(self): print("C")
class D(B, C):
    pass

D().hi()                  # B  按 MRO 找第一个有 hi 的
print(D.__mro__)
# (D, B, C, A, object)
```

**简单理解 C3**：从左往右深度优先，但保证子类总在父类之前 — 不会出现"继承了 B 但走 A"。

[[MRO 与 C3 线性化]]

> 💡 多继承容易乱，能不用就不用。可以用 **mixin**（专门提供一组方法的小类）来组合。

## 7. 多态：同一个调用，不同表现 🎭

```python
class Animal:
    def __init__(self, name):
        # 两个子类都只传一个 name，说明基类只需要存这个名字
        self.name = name

    def speak(self):
        # 基类给出「默认行为」：动物都会叫，但不知道怎么叫。
        # 子类覆盖它来提供具体叫声。
        # 也可以改成 raise NotImplementedError 强制子类实现——
        # 那是「抽象方法」的写法，这里保留一个可运行的默认版本。
        print(f"{self.name} 发出了声音")


class Cat(Animal):
    def speak(self):                      # 覆盖 Animal.speak
        print("喵")


class Dog(Animal):
    def speak(self):                      # 覆盖 Animal.speak
        print("汪")


for pet in [Cat("咪咪"), Dog("旺财")]:
    pet.speak()
```

> 💡 多态让代码"对接口编程，不对实现编程"，扩展性强。

## 8. 魔术方法（dunder）✨

| 方法            | 触发时机                  |
| ------------- | --------------------- |
| `__init__`    | 创建实例                  |
| `__repr__`    | `repr(x)` / 调试输出      |
| `__str__`     | `print(x)` / `str(x)` |
| `__eq__`      | `x == y`              |
| `__hash__`    | 用作 dict 键 / set 元素    |
| `__len__`     | `len(x)`              |
| `__getitem__` | `x[i]`                |
| `__setitem__` | `x[i] = v`            |
| `__call__`    | `x()` 把实例当函数用         |
| `__add__`     | `x + y`               |

```python
class Vector:
    def __init__(self, x, y):
        # 构造：Vector(1, 2) 时自动调用
        self.x, self.y = x, y

    def __repr__(self):
        # repr() / print() / f-string 的 !r 都走这里。
        # 目的是给开发者看的「可复现」字符串，
        # 理想情况下 eval(repr(v)) == v。
        return f"Vector({self.x}, {self.y})"

    def __add__(self, other):
        # 支持 v1 + v2。左侧操作数是 self，右侧是 other。
        # 返回一个新 Vector，不修改 self 或 other（不可变风格）。
        return Vector(self.x + other.x, self.y + other.y)

    def __eq__(self, other):
        # 支持 v1 == v2。按「坐标相等」定义相等。
        # 注意：定义了 __eq__ 之后，Python 会把 __hash__ 设为 None，
        # 这个类的实例就不可哈希了（不能放进 set、不能当 dict 键）。
        return (self.x, self.y) == (other.x, other.y)

    def __len__(self):
        # 支持 len(v)。这里把「向量有几个分量」定义为 2。
        # 副作用：对象变成「真值」判断的依据 —— bool(v) 为 True（2 != 0）。
        return 2

    def __getitem__(self, i):
        # 支持 v[0] / v[1] / v[-1] / 切片。
        # 内部把坐标装进 tuple 再索引，所以负下标、切片都自动可用。
        # 副作用：有了 __getitem__，对象就「可迭代」了
        # （for 循环会从 i=0 开始取，取到 IndexError 为止）。
        return (self.x, self.y)[i]

    def __call__(self, scale):
        # 支持 v(10)，让实例「像函数一样」被调用。
        # 返回缩放后的新 Vector。不要和 __init__ 搞混：__init__ 只在构造时调一次。
        return Vector(self.x * scale, self.y * scale)


v1 = Vector(1, 2); v2 = Vector(3, 4)
print(v1 + v2)              # Vector(4, 6)      ← __add__ + __repr__
print(v1 == Vector(1, 2))   # True              ← __eq__
print(len(v1))              # 2                 ← __len__
print(v1[0], v1[1])         # 1 2               ← __getitem__
print(v1(10))               # Vector(10, 20)    ← __call__
```

> 💡 写完魔术方法，类就**像内置类型一样自然**。

## 9. `@property`：把方法变属性 🪄

```python
class Circle:
    def __init__(self, r):
        # 用 _r 而不是 r：单下划线是「内部使用，外部别碰」的约定（不是强制私有）。
        # 这里直接写 _r 而不是 self.radius = r，是刻意绕过 setter；
        # 如果希望构造时也校验半径，应改成 self.radius = r（会走下面的 setter）。
        self._r = r

    @property
    def radius(self):
        # @property 把方法「变成属性」：外部用 c.radius 访问，不写括号。
        # 方法名 radius 就是属性名，之后 setter 要靠这个名字挂上去。
        return self._r

    @radius.setter
    def radius(self, value):
        # 装饰器名必须是「属性名.setter」，且方法名也要叫 radius；
        # 写成别的名字不会报错，但不会生效（常见坑）。
        # 这里给 self._r 赋值，不能写 self.radius = value —— 那会再次进入 setter，
        # 无限递归直到 RecursionError。
        if value < 0:
            raise ValueError("半径不能为负")
        self._r = value

    @property
    def area(self):
        # 只读属性：只有 getter，没有 setter。
        # c.area = 10 会抛 AttributeError。
        # 每次访问都重新计算，不做缓存 —— 半径变了面积自然跟着变，无需手动同步。
        return 3.14159 * self._r ** 2


c = Circle(3)
print(c.radius)    # 3        — 不用括号，读走 getter
print(c.area)      # 28.27... — 只读，实时计算
c.radius = 5       # 赋值时会进 setter，自动校验
# c.radius = -1    # ❌ ValueError: 半径不能为负
# c.area = 10      # ❌ AttributeError: property 'area' has no setter
```

> 💡 `@property` 让你**先写公开属性，再加校验**，不破坏调用代码。

## 10. dataclass：少写 90% 模板 🪶

```python
from dataclasses import dataclass

@dataclass
class Point:
    # 类体里只写「字段名: 类型」，dataclass 装饰器负责生成
    # __init__ / __repr__ / __eq__（默认还有 __hash__ 的规则见后文）
    x: int
    y: int = 0           # 有默认值的字段必须排在无默认值字段之后

p1 = Point(1, 2)
p2 = Point(1, 2)
print(p1)            # Point(x=1, y=2)   ← 自动 __repr__，包含全部字段
print(p1 == p2)      # True              ← 自动 __eq__，按字段逐项比较
```

等价于

```python
class Point:
    def __init__(self, x, y=0):
        self.x = x
        self.y = y
    def __repr__(self):
        return f"Point(x={self.x!r}, y={self.y!r})"
    def __eq__(self, other):
        if other.__class__ is not self.__class__:
            return NotImplemented
        return (self.x, self.y) == (other.x, other.y)
```

`@dataclass` 自动生成 `__init__` / `__repr__` / `__eq__`，专为"数据载体类"设计。

```python
@dataclass(frozen=True)        # frozen=True → 不可变
class Money:
    amount: float
    currency: str = "CNY"
```

## 11. enum：枚举值 🚥

```python
from enum import Enum

class Color(Enum):
    # 类体里写「名字 = 值」，每一项自动成为一个「成员」。
    # RED / GREEN / BLUE 不是普通类属性，而是 Color 的实例。
    # 值可以是任意类型（int、str、tuple…），不要求连续或从 1 开始。
    RED = 1
    GREEN = 2
    BLUE = 3

c = Color.RED
# .name  是成员名（字符串 "RED"）
# .value 是定义时赋的值（1）
# print(c) 走的是 Enum 自带的 __str__，输出 "Color.RED"
print(c, c.name, c.value)     # Color.RED RED 1

# 按「值」反查成员：Color(1) 等价于 Color.RED。
# 找不到会抛 ValueError，不是返回 None。
print(Color(1))               # Color.RED

# 同一成员与自身比较恒为 True；Enum 的 __eq__ 是身份比较，
# 不同成员之间、成员与非成员之间一律 False（不会跨类型相等）。
print(Color.RED == Color.RED) # True
```

> 💡 用枚举代替"魔法数字 / 魔法字符串"，代码更安全。

## 12. 元类与描述符：类是怎么被造出来的 🧙

前面 11 节讲的都是"怎么用类"。这一节讲一层：**类本身也是对象**，它由谁造出来？造出来之后又怎么控制属性的读写？

这一节是本章的"内功"。读不懂也没关系——但读懂之后，Pydantic、FastAPI、SQLAlchemy、attrs 这些库为什么能做到"读一次类型注解就生成一堆代码"，你就有答案了。

### 12.1 元类 metaclass：类的类 🏛️

**类比**：普通对象是"用模具造出来的产品"，类是"模具"。那模具本身是谁造的？**元类**。

Python 里 `type` 就是所有类的默认元类：

```python
class Dog:
    pass

print(type(Dog))          # <class 'type'>   Dog 的元类是 type
print(type(type))         # <class 'type'>   type 自己也是 type 造的（鸡生蛋）
print(isinstance(Dog, type))   # True —— Dog 是 type 的实例
```

想定制"造类"的过程，就写一个继承 `type` 的元类：

```python
class Tagged(type):
    """给所有带这个元类的类自动加一个 tag 属性"""
    def __new__(mcls, name, bases, namespace, **kwargs):
        cls = super().__new__(mcls, name, bases, namespace, **kwargs)
        cls.tag = "tagged"
        return cls

class Dog(metaclass=Tagged):
    pass

print(Dog.tag)             # tagged —— 造 Dog 的时候自动加上的
print(Dog().tag)           # tagged 实例也能看到（类属性）
```

关键点：元类的 `__new__` 返回的**就是那个类本身**，所以你可以在类创建时做任何加工（改名字、加属性、注册到某个表里）。

> 💡 真实世界里：ORM 的"模型注册表"、Django 的 `ModelBase`、Pydantic 的 `ModelMetaclass`，全是元类干的活。

### 12.2 `__init_subclass__`：不写元类也能定制子类 🪄

90% 的"定制类"需求，用 `__init_subclass__` 就够了——它是**类方法**，在**子类被创建的那一刻**自动调用：

```python
class Base:
    def __init_subclass__(cls, /, register=True, **kwargs):
        super().__init_subclass__(**kwargs)
        if register:
            REGISTRY.append(cls.__name__)

REGISTRY = []

class Alpha(Base):
    pass

class Beta(Base, register=False):   # 显式关掉
    pass

print(REGISTRY)         # ['Alpha']
```

注意它接收**类方法的关键字参数**——写 `class Beta(Base, register=False)` 时，`register=False` 会传给 `__init_subclass__`，而**不会**传给 `type.__new__`。这就是 `**kwargs` 转发那一行的作用。

### 12.3 描述符 descriptor：属性读写的真正主角 🎯

**描述符 = 任何定义了 `__get__` / `__set__` / `__delete__` 之一的对象**。当它被放在**类的属性**上时，属性访问就会被它接管。

第 9 节的 `@property` 其实就是一个描述符。我们把它拆开看：

```python
class Celsius:
    """把摄氏度存成华氏度，取的时候再换回来"""
    def __set_name__(self, owner, name):
        # 类创建时自动调用，告诉你"你被挂到了哪个名字上"
        self.private = "_" + name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self          # 通过类访问时返回描述符自己
        return getattr(obj, self.private)

    def __set__(self, obj, value):
        setattr(obj, self.private, value * 9 / 5 + 32)

class Weather:
    temp = Celsius()             # 描述符实例，必须放在【类】里

w = Weather()
w.temp = 100                    # 触发 __set__：存进去的是 212.0
print(w.temp)                   # 触发 __get__：返回 212.0
```

**为什么 `obj is None` 那行不能少？** 因为 `Weather.temp` 是从**类**上访问属性，此时没有实例，Python 会调用 `__get__(None, Weather)`。不处理 `None` 就会在 `getattr(None, ...)` 上炸掉。

### 12.4 数据描述符 vs 非数据描述符：谁优先？⚖️

这是描述符唯一需要背下来的规则：

| 类型 | 条件 | 与实例 `__dict__` 的优先级 |
|---|---|---|
| **数据描述符** | 定义了 `__set__` 或 `__delete__` | **更高** —— 实例字典同名也盖不住它 |
| **非数据描述符** | 只定义了 `__get__` | 更低 —— 实例字典里同名的值会盖住它 |

```python
class Getter:                       # 只有 __get__ → 非数据描述符
    def __get__(self, obj, objtype=None):
        return "computed"

class Setter:                       # 有 __get__ + __set__ → 数据描述符
    def __get__(self, obj, objtype=None):
        return obj.__dict__.get("_v", 0)
    def __set__(self, obj, value):
        obj.__dict__["_v"] = value * 2

class C:
    a = Getter()
    b = Setter()

c = C()
c.__dict__["a"] = "from instance"    # 实例字典里塞了一个同名值
print(c.a)               # from instance —— 非数据描述符被实例字典盖住了
print(c.b)               # 0             —— 数据描述符优先级更高，实例字典盖不住它
```

**这也解释了普通方法为什么是"非数据描述符"**：`obj.method` 时 Python 找到类里的函数（它有 `__get__`），调用 `__get__(obj, C)` 把 `obj` 绑定进去，于是变成 `bound method`。所以 `self` 是自动传进来的——**不是因为约定，是因为描述符协议**。

> 💡 官方文档：[Descriptor HowTo Guide](https://docs.python.org/3/howto/descriptor.html) —— 本节内容主要来自这份官方指南，想深入可以对着读。

### 12.5 `__slots__`：省内存 + 顺手挡住错别字 📦

默认情况下每个实例都有一个 `__dict__`，随便加属性。用 `__slots__` 可以把它换成固定长度的槽位：

```python
class Point:
    __slots__ = ("x", "y")        # 只能有这两个属性

p = Point()
p.x = 1
print(p.x)                       # 1 —— 正常读

try:
    p.y                          # 还没赋值 → AttributeError
except AttributeError as e:
    print("AttributeError:", e)

try:
    p.z = 3                      # ❌ 拼写错误 / 未声明的属性
except AttributeError as e:
    print("AttributeError:", e)
```

输出：

```text
1
AttributeError: 'Point' object has no attribute 'y'
AttributeError: 'Point' object has no attribute 'z' and no __dict__ for setting new attributes
```

好处有两个：

1. **立刻暴露拼写错误**——`id_nubmer` 这种手滑当场报错，而不是静默存进去。
2. **省内存**——官方文档给的数据：64 位 Linux 上，一个带两个属性的实例，`__slots__` 版 48 字节，普通版 152 字节（存几十万对象时差别显著）。

代价是：**实例不能再有动态属性**，也不能在没定义 `__slots__` 的类上继承 `__slots__`（除非所有基类都定义了）。

> 💡 `functools.cached_property` 依赖实例 `__dict__`，所以带 `__slots__` 的类用不了它——这是 12.4 那条"数据描述符优先级"规则的现实体现。

## 13. 实战 1：完整 Vector 类 ➕

```python
import math
from dataclasses import dataclass

@dataclass
class Vec:
    # 两个字段都是 float。注解不强制运行时类型，传 int 也照收，
    # 只是参与运算后结果可能是 int 或 float —— 这里没有做统一转换。
    x: float
    y: float

    def __add__(self, other):
        # 支持 a + b。返回值是新 Vec，不修改 a 或 b。
        # 注意：没有检查 other 的类型。a + 1 会在 other.x 处抛 AttributeError，
        # 报错信息对调用方不友好（改进见下文「几个值得展开的点」第 2 条）。
        return Vec(self.x + other.x, self.y + other.y)

    def __sub__(self, other):
        # 支持 a - b，同样返回新对象。
        return Vec(self.x - other.x, self.y - other.y)

    def __mul__(self, k):
        # 只处理「Vec * 标量」。k 被当作标量，乘到每个分量上。
        # ⚠️ 这里没写 __rmul__，所以 3 * a 会走 int.__mul__(3, a)，
        # int 不认识 Vec，返回 NotImplemented，最终 TypeError。
        # 要支持「标量 * Vec」，必须补 __rmul__（见第 3 条）。
        return Vec(self.x * k, self.y * k)

    def length(self):
        # math.hypot(x, y) 等价于 sqrt(x² + y²)，但内部算法避免了
        # 中间平方导致的溢出/下溢，比 math.sqrt(x**2 + y**2) 更稳。
        # 这是普通方法，不是 property —— 调用要写 a.length()。
        return math.hypot(self.x, self.y)


a = Vec(1, 2); b = Vec(3, 4)
print(a + b)              # Vec(x=4, y=6)        ← __add__ + dataclass 的 __repr__
print((b - a).length())   # 2.828...             ← __sub__ 返回 Vec，再调 length
print(a * 3)              # Vec(x=3, y=6)        ← __mul__
```

## 14. 实战 2：银行账户体系 🏦

```python
class Account:
    def __init__(self, owner, balance=0):
        # 单下划线 _balance 是「内部使用」的约定，不是真正的私有。
        # 暴露给外部的是下面只读的 balance property。
        self.owner = owner
        self._balance = balance

    def deposit(self, n):
        # ⚠️ 没有校验 n > 0。传负数就变成「反向取款」，且绕过了 withdraw 的余额检查。
        self._balance += n

    def withdraw(self, n):
        # 基础账户不允许透支：取款额超过余额就拒绝。
        if n > self._balance:
            raise ValueError("余额不足")
        self._balance -= n

    @property
    def balance(self):
        # 只读：只有 getter，没有 setter。
        # 外部 a.balance = 100 会抛 AttributeError，强制走 deposit/withdraw。
        return self._balance

    def __repr__(self):
        # type(self).__name__ 而不是写死 "Account"：
        # 子类实例调用时自动打印子类名，不需要每个子类重写 __repr__。
        return f"<{type(self).__name__} {self.owner} ¥{self._balance}>"


class SavingsAccount(Account):
    def __init__(self, owner, balance=0, rate=0.03):
        # 先让父类初始化 owner 和 _balance，再补上子类自己的 rate。
        # 忘了这句 super().__init__ 的话，_balance 根本不存在。
        super().__init__(owner, balance)
        self.rate = rate

    def add_interest(self):
        # 直接改 _balance，没有走 deposit —— 这是「内部操作」，
        # 但如果将来所有余额变动都要记日志/触发事件，这里就漏掉了。
        # 更稳妥的写法是 self.deposit(self._balance * self.rate)。
        self._balance *= (1 + self.rate)


class CheckingAccount(Account):
    # 类属性，不是实例属性。所有 CheckingAccount 实例共享同一个值；
    # self.OVERDRAFT 沿 MRO 查到类上，实例 __dict__ 里并没有这个键。
    OVERDRAFT = -1000

    def withdraw(self, n):           # 重写：允许透支 1000
        # 检查「取完后余额不能低于 -1000」，等价于 n > balance + 1000 时报错。
        # self._balance - self.OVERDRAFT = self._balance - (-1000) = balance + 1000
        if n > self._balance - self.OVERDRAFT:
            raise ValueError("超出透支限额")
        self._balance -= n

s = SavingsAccount("李雷", 1000)
s.add_interest()
print(s)                              # <SavingsAccount 李雷 ¥1030.0>

c = CheckingAccount("韩梅梅", 500)
c.withdraw(800)                       # 允许透支：500 - 800 = -300，未低于 -1000
print(c)                              # <CheckingAccount 韩梅梅 ¥-300>
```

## 15. 实战 3：扑克牌发牌器 🃏

```python
import random
from dataclasses import dataclass

@dataclass(frozen=True)
class Card:
    # frozen=True 两个作用：实例不可变（牌不能被改）+ 自动生成 __hash__。
    # 后者很重要：dataclass 默认生成 __eq__ 会禁用 __hash__，
    # 加 frozen 才让 Card 能进 set、能当 dict 键（去重、判重时要用）。
    rank: str
    suit: str

    def __repr__(self):
        # 覆盖 dataclass 自动生成的 __repr__（原本是 Card(rank='A', suit='♠')）。
        # 牌面显示讲究紧凑，牌桌上没人想看字段名。
        # 代价：eval(repr(c)) 不再是 Card —— 调试时不能直接复制回构造调用。
        return f"{self.rank}{self.suit}"


class Deck:
    # 类属性，所有 Deck 实例共享。RANKS 用 list(...) 而不是字符串，
    # 是为了让 "TJQKA" 里每个字符各自成为一个元素；
    # SUITS 是字符串，迭代时同样逐字符 —— 两者在下面的推导式里用法一致。
    RANKS = list("23456789TJQKA")
    SUITS = "♠♥♦♣"

    def __init__(self):
        # 两层推导式：外层 rank、内层 suit，生成 52 张不重复的牌。
        # random.shuffle 是原地洗牌，直接改 self.cards，返回 None。
        self.cards = [Card(r, s) for r in self.RANKS for s in self.SUITS]
        random.shuffle(self.cards)

    def deal(self, n):
        # 发 n 张：切片拿前 n 张，剩下的重新赋回 self.cards。
        # self.cards[:n] 是「新 list」，self.cards[n:] 也是新 list，
        # 所以 hand 和 self.cards 不共享底层数据，后续互不影响。
        # ⚠️ n > len(self) 时不会报错，切片会「尽力而为」返回剩下的全部；
        #    想严格校验需自己加 if n > len(self.cards): raise ValueError(...)。
        hand, self.cards = self.cards[:n], self.cards[n:]
        return hand

    def __len__(self):
        # 支持 len(deck)，返回剩余牌数。
        # 副作用：len(deck) == 0 时 bool(deck) 为 False，
        # 所以发空牌堆后可以直接 if not deck: 判断「牌没了」。
        return len(self.cards)


deck = Deck()
print(deck.deal(5))     # 例：[8♥, A♠, 3♣, ...]  ← 每次运行顺序不同（已洗牌）
print("剩余", len(deck))  # 47
```

## 🐛 常见错误集合

| 错误                                  | 原因                |
| ----------------------------------- | ----------------- |
| 忘写 `self`                           | 实例方法第一个参数必须是 self |
| `__init__` 没写 `self.x =`            | 属性没绑到实例           |
| 类属性和实例属性混淆                          | 类属性是共享的           |
| 子类 `__init__` 没调 `super().__init__` | 父类属性没初始化          |
| 多继承找不到方法                            | 看 `__mro__`       |
| 描述符里的 `getattr(obj, ...)` 报 `AttributeError` | 通过**类**访问时 `obj` 是 `None`，要先判断 `obj is None` |
| `__slots__` 之后还想加动态属性               | `__slots__` 只允许列出的属性，要动态属性就别用 |
| 子类没继承父类的 `__slots__` 就想省内存         | 所有基类都要定义 `__slots__` |
