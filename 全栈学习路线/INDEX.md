## ❓ 常见问题 FAQ

### Q1：要全部学完才能开始毕业项目吗？
不需要。**01-04 是主线**，05 / 07-08 可以与毕业项目并行补。但 08 没学完，写不出真正的 Agent 产品。

### Q2：每天要花多少时间？
- 全职转行：6-8 小时/天，9-12 个月
- 在职学习：2-3 小时/天，12-18 个月
- 周末战士：1 天/周，2-3 年（可行但慢）

### Q3：可以跳过 Python，直接用 TypeScript 做后端吗？
可以。推荐 Python（FastAPI）是因为 AI 生态最成熟；只做 Web 的话 Node + Hono 也行，第 05 章两条线都讲。

### Q4：必须用 Claude 吗？换 GPT / Gemini / 开源模型行不行？
完全可以。本路线代码 90% 是模型无关的，换 API key 就好。Claude 是因为长文本 + 工具调用 + 编码能力最强而首选。

### Q5：我没有数学背景，能学 AI 吗？
能。本路线是 **AI 应用层**（API + RAG + Agent），不是 **AI 算法层**（炼模型）。前者只需高中数学；只有 07-W06「从零实现 GPT」会用到一点微积分和矩阵。

### Q6：我电脑配置很差，能跑动吗？
能。全部用云端 API + 云端部署，本地只跑 Node + Python，4GB 内存够用（06 章 K8s 部分建议用云上免费额度）。

### Q7：学完能找到工作吗？
- 国内 AI 应用工程师：YES，有项目就行
- 国外远程：YES，但要求英语 + 作品集 + GitHub 活跃
- 大厂算法岗：本路线不直接对口，需要补研究背景

### Q8：毕业项目可以直接做副业赚钱吗？
可以。第 9 章就是教这个。但平均独立开发者**第一年 MRR < $500**，请有合理预期。

### Q9：路线过时了怎么办？
以每个文件 frontmatter 里的 `updated` 字段为准 —— 这个日期是从 git 提交历史自动推导的（该文件正文最后一次被改动的提交日），不是手写维护的，所以可信。日期旧的内容优先对照官方文档。**底层架构思想 5 年不会变，学方法 > 学具体工具**。

### Q10：学到一半想放弃怎么办？
1. **降低强度**：3 小时降到 1 小时，不要断
2. **找学习同伴**：找一个能每周对账的人
3. **去做项目**：理论卡住就直接做，缺什么补什么
