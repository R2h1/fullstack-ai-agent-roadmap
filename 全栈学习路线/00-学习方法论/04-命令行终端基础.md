# 命令行终端基础

> 图形界面是开车，命令行是骑摩托——后者风更大，但更快、更灵活，能钻进小巷。

## 🎯 本章目标

- 知道为什么图形界面和命令行是两种不同的生产力（不是谁取代谁）
- 看懂文件系统的目录结构和 `~ / . ..` 这些符号
- 熟练使用 28 个核心命令（45 条典型用法）：导航、文件、查看、搜索、权限、进程、网络、压缩
- 会用管道 `|` 和重定向 `>` `>>` 把命令串起来
- 搞清楚 PATH 和环境变量，能自己往 `~/.zshrc` 里加一条 alias
- 养成用 `Tab` 补全、`Ctrl+R` 搜历史的肌肉记忆

## 一、为什么程序员要会用终端？🏍️

| 任务          | 图形界面 | 命令行              |
| ----------- | ---- | ---------------- |
| 改 1 个文件名    | 双击改  | `mv a.txt b.txt` |
| 改 1000 个文件名 | 改到崩溃 | 一行命令搞定           |
| 远程操作服务器     | ❌ 不行 | ✅ SSH            |
| 自动化任务       | 难    | 写脚本就行            |
| 给同事演示步骤     | 录屏   | 复制粘贴命令           |

90% 的开发工具（git、docker、npm、python）都是命令行优先的。**学会终端 = 解锁程序员的真正生产力**。

## 二、文件系统结构 🗂️

Linux/macOS 的目录是树状的，从 `/`（根目录）开始：

```
/                ← 根目录（一切的起点）
├── bin/         ← 系统命令（ls、cp 这些）
├── etc/         ← 系统配置
├── home/        ← 普通用户的家
│   └── alice/   ← 用户 alice 的家目录
├── usr/         ← 第三方软件
├── var/         ← 日志、缓存
└── tmp/         ← 临时文件
```

几个关键符号：

| 符号   | 含义      | 例子            |
| ---- | ------- | ------------- |
| `/`  | 根目录     | `/etc/hosts`  |
| `~`  | 当前用户家目录 | `~/Documents` |
| `.`  | 当前目录    | `./script.sh` |
| `..` | 上级目录    | `cd ..`       |
| `-`  | 上一次所在目录 | `cd -`        |

> macOS 上你的家目录是 `/Users/你的用户名`；Linux/WSL 上是 `/home/你的用户名`。`~` 是它的别名。

## 三、必会命令场景手册 🛠️（45 条用法 / 28 个命令）

> 这一节是全章的地基，共 8 组、45 条用法（去重后是 28 个命令，很多命令会用在不同场景里）。每组都标注了「什么时候用」，按场景记比按字母记快得多。

### 导航三剑客

```bash
pwd              # 我现在在哪？(Print Working Directory)
ls               # 这个目录里有啥？
ls -la           # 包括隐藏文件 + 详细信息
cd /path/to/dir  # 去某个目录
cd ~             # 回家
cd -             # 回上一次
```

### 文件操作

```bash
mkdir my-dir              # 建目录
mkdir -p a/b/c            # 一次建多层
touch a.txt               # 建空文件 / 更新时间戳
cp a.txt b.txt            # 复制
cp -r dir1 dir2           # 递归复制目录
mv a.txt c.txt            # 重命名
mv a.txt /tmp/            # 移动
rm a.txt                  # 删文件
rm -rf dir                # 递归强删目录 ⚠️ 极度危险
```

> ⚠️ **`rm -rf /` 会删掉你的整个系统**。终端没有回收站，删了就没了。

### 查看内容

```bash
cat file.txt              # 整个倒出来
less file.txt             # 分页看（按 q 退出）
head -n 20 file.txt       # 前 20 行
tail -n 20 file.txt       # 后 20 行
tail -f log.txt           # 实时跟踪文件追加（看日志神器）
```

### 搜索

```bash
grep "hello" file.txt          # 在文件里找"hello"
grep -r "TODO" .               # 当前目录递归找
grep -i "Error" log.txt        # 不区分大小写
find . -name "*.py"            # 找所有 .py 文件
find . -type f -size +10M      # 大于 10MB 的文件
```

### 权限

```bash
chmod +x script.sh        # 加上可执行权限
chmod 755 file            # 数字写法
chown alice:alice file    # 改所有者
ls -l                     # 看权限：-rwxr-xr-x
```

权限三组字母：所有者 / 同组 / 其他人。`rwx` = 读写执行。

### 进程

```bash
ps aux              # 列出所有进程
ps aux | grep node  # 找 node 进程
top                 # 实时进程监视（q 退出）
htop                # 更好看的 top（需要装：brew install htop）
kill 1234           # 杀进程号 1234（先礼后兵：先普通 kill）
kill -9 1234        # 强杀 ⚠️ 最后手段：进程收不到 SIGTERM 才会用，副作用是数据来不及保存
```

> ⚠️ **`kill -9` 是最后手段**，它直接 SIGKILL 进程，程序没有机会保存数据或清理临时文件。
> 顺序永远是：先 `kill <PID>` → 无效再 `kill -9 <PID>`。

### 网络

```bash
curl https://api.github.com         # 发 HTTP 请求
curl -O https://xx.com/file.zip     # 下载文件
wget https://xx.com/file.zip        # 也是下载
ping google.com                     # 测连通
ssh user@server.com                 # 远程登录
scp file.txt user@server:/tmp/      # 远程拷贝
```

### 压缩

```bash
tar -czf x.tar.gz dir/              # 打包压缩
tar -xzf x.tar.gz                   # 解压
zip -r x.zip dir/                   # zip 压缩
unzip x.zip                         # zip 解压
```

### 自我检查 ✅

跑下面这串练手：

```bash
cd ~
mkdir terminal-test
cd terminal-test
echo "hello world" > a.txt
cat a.txt
cp a.txt b.txt
ls -la
grep "hello" a.txt
cd ..
rm -rf terminal-test
```

## 四、管道 `|` 与重定向 `>` `>>` 🔌

### 重定向 —— 把输出存到文件

```bash
echo "hello" > a.txt        # 写入（覆盖）
echo "world" >> a.txt       # 追加
ls -la > files.txt          # 把 ls 的输出存进文件
command 2> error.log        # 把错误信息存进 error.log
command > out.log 2>&1      # 把正常输出和错误都存到 out.log
```

### 管道 —— 把上一个命令的输出，喂给下一个命令

```bash
ls | grep ".py"                    # 列出 .py 结尾的
cat log.txt | grep "ERROR" | wc -l # 统计 ERROR 行数
ps aux | grep python | head -5     # 前 5 个 python 进程
history | grep git                 # 在历史命令里找 git
```

类比：管道 `|` 就像工厂流水线，每道工序加工后传给下一道。

## 五、环境变量与 PATH 🛤️

### 什么是环境变量？

可以理解为系统的"全局配置项"。

```bash
echo $HOME             # 你的家目录
echo $USER             # 当前用户
echo $SHELL            # 当前 shell
echo $PATH             # 重点！见下方
```

### PATH 是什么？

PATH 是一串目录，**当你输入一个命令时，系统会按顺序在这些目录里找它**。

```bash
echo $PATH
# /usr/local/bin:/usr/bin:/bin:/usr/sbin:...
```

> 这就解释了为什么有时候 `command not found` —— 程序装在了 PATH 之外的地方。

### 怎么改 PATH？

编辑 `~/.zshrc`（或 `~/.bashrc`），加一行：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

然后：

```bash
source ~/.zshrc       # 让改动立即生效
```

## 六、`~/.zshrc` 配置文件 ⚙️

`~/.zshrc` 是 Zsh 启动时自动执行的脚本，每次开终端都会跑一遍。

常见配置：

```bash
# 别名（让长命令变短）
alias ll='ls -la'
alias gs='git status'
alias gp='git pull'
alias ..='cd ..'

# 环境变量
export EDITOR='code --wait'
export PATH="$HOME/.local/bin:$PATH"

# 函数
mkcd() { mkdir -p "$1" && cd "$1"; }
```

改完 `source ~/.zshrc` 生效。

## 七、常用快捷键 ⌨️

| 快捷键       | 作用                       |
| --------- | ------------------------ |
| `Tab`     | 自动补全（**最重要的快捷键**）        |
| `Ctrl+C`  | 中断当前命令                   |
| `Ctrl+D`  | 退出当前 shell / 结束输入        |
| `Ctrl+L`  | 清屏（等同 `clear`）           |
| `Ctrl+R`  | 搜索历史命令（再按一次 Ctrl+R 翻下一个） |
| `Ctrl+A`  | 光标到行首                    |
| `Ctrl+E`  | 光标到行尾                    |
| `Ctrl+U`  | 删到行首                     |
| `Ctrl+K`  | 删到行尾                     |
| `Ctrl+W`  | 删一个单词                    |
| `↑` / `↓` | 翻历史命令                    |
| `!!`      | 上一条命令                    |
| `!$`      | 上一条命令的最后一个参数             |

🔥 **Ctrl+R 一定要会**！它是你穿越历史命令的传送门。

## 八、本章实战：做一个纯命令行的小工具 🛠️

把这一章的命令串起来，做一个自己每天都会用的小工具。

### 需求

写一个 `note.sh`：往今天的笔记文件里追加一条记录。

```bash
./note.sh "今天学了什么"
```

### 技术要求

- 纯 bash，不装任何第三方工具
- 用 `date` 生成当天日期，文件名形如 `~/notes/2026-11-23.md`
- 用 `>>` **追加**，绝不覆盖已有笔记
- 用 `$1` 取第一个参数；没有参数时打印用法并退出（退出码 1）
- 每条记录后面加一行 `---` 分隔，方便以后 `grep` 检索
- 给它加可执行权限：`chmod +x note.sh`

### 验收标准

- [ ] `chmod +x note.sh` 之后，`./note.sh "hello"` 能创建（或追加）今天的笔记文件
- [ ] 连续跑两次，两条记录都在（验证用的是 `>>` 而不是 `>`）
- [ ] 不带参数运行会打印用法，且 `echo $?` 返回 1
- [ ] `cat ~/notes/<今天的日期>.md` 能看到你写的记录
- [ ] 提交到 GitHub，commit message 符合约定式提交规范

> 想更进一步：把脚本放进 `~/bin/`，再写进 PATH，这样在任何目录都能直接 `note "..."`。

## 九、🐛 常见错误 🚨

先查速查表，再往下看细节。

| 错误现象 | 原因 | 解决 |
|---|---|---|
| `command not found: xxx` | 没装，或装了但不在 PATH 里 | `which xxx` 看路径；`echo $PATH` 看是否包含；加 `export PATH="..."` 到 `~/.zshrc` |
| `permission denied` | 没有执行权限，或文件属于别人 | `chmod +x 文件名`；家目录里的操作不该需要 `sudo`，需要 `sudo` 说明前面错了 |
| `No such file or directory` | 路径写错，或文件真的不在 | `pwd` 看当前位置，`ls` 看有没有；注意 Linux/macOS **区分大小写** |
| `rm: cannot remove 'x': Is a directory` | 少了 `-r` | `rm -r 目录`（`-rf` 更暴力，慎用） |
| `rm -rf` 误删了重要文件 | 终端没有回收站 | **立即停止操作**；在 git 仓库里用 `git checkout HEAD -- 文件名` 找回；不在仓库里就基本没了 |
| 管道 `|` 没生效 | 把命令写在了引号里，或者用错了 `\|` | 管道必须在引号外；`cmd1 \| cmd2` |
| `>` 覆盖了文件内容 | `>` 是覆盖不是追加 | 用 `>>` 追加；养成「先 `>` 写草稿，确认后再 `mv`」的习惯 |
| `Ctrl+C` 按了没反应 | 程序在等输入或卡在 I/O | 再按一次；实在不行 `Ctrl+Z` 挂起，用 `jobs` / `fg` 恢复 |
| `kill -9` 后进程还在 | 进程已变成僵尸，或 PID 写错 | `ps aux \| grep 名字` 重新确认 PID；`kill -9` 是最后手段，先试 `kill` |
| 终端输出乱码 / 中文显示异常 | 编码不是 UTF-8 | `export LANG=zh_CN.UTF-8`；老 Mac 终端还要把编码设为 UTF-8 |
| `mkdir` 说目录已存在 | 目录真的存在 | 加 `-p` 幂等创建：`mkdir -p a/b/c` |
| `ssh` 连不上服务器 | 端口 / 密钥 / 网络任一问题 | `ssh -v user@host` 看详细日志；确认端口和 `~/.ssh/config` |
| `tar` 解压报 "not in gzip format" | 压缩格式和命令不匹配 | `.zip` 用 `unzip`，`.tar.gz` 用 `tar -xzf`，`.tar` 用 `tar -xf` |

### `command not found`

参考第五节。多半是 PATH 没配好。

### `permission denied`

```bash
ls -l file.txt        # 看权限
chmod +x file.sh      # 加执行权限
sudo command          # 用管理员（谨慎）
```

### `No such file or directory`

路径写错了。检查：

```bash
pwd                   # 我在哪？
ls                    # 我能看到这个文件吗？
```

注意大小写——Linux/macOS **区分大小写**！

### 卡住了 / 不动了

按 `Ctrl+C` 中断。如果是某个程序卡死：

```bash
ps aux | grep 卡死的程序名
kill 进程号        # 先试温和的 SIGTERM
kill -9 进程号     # 实在不行再强杀（⚠️ 数据来不及保存）
```

### 不小心 `rm -rf` 删了重要文件

😱 **没有回收站**。如果在 git 仓库里、且之前 commit 过：

```bash
git checkout HEAD -- 文件名
```

否则只能去找数据恢复软件，但希望渺茫。**永远先备份再 `rm`！**
