## 1. 函数：可复用的微波炉 ♨️

**类比**：函数 = 微波炉。**输入**（食材）→ **加热**（处理）→ **输出**（熟食）。
你不需要每次都重新造一个微波炉，只要按按钮就好。

### 1.1 定义与调用
```python
def greet(name):              # def 定义，name 是参数
    return f"你好，{name}"     # return 把结果"端出来"

msg = greet("小明")            # 调用
print(msg)                    # 你好，小明
```

**逐行**：
- `def` 是关键字，告诉 Python "下面这块是个函数"
- `name` 是**形式参数**（站位的标签），调用时把"小明"塞进 `name`
- `return` 把结果交给外面；如果没有 `return`，函数返回 `None`

### 🎯 练习
写一个函数 `is_even(n)` 返回 n 是否偶数。

<details>
<summary>答案</summary>

```python
def is_even(n):
    return n % 2 == 0
print(is_even(4))   # True
```
</details>

## 2. 参数的 4 种形式 🎛️

```python
def order(name, size="中杯", *toppings, **options):
    print(f"{name} 一杯 {size}")
    print("加料：", toppings)
    print("配置：", options)

order("拿铁")
# 拿铁 一杯 中杯
# 加料：()
# 配置：{}

order("美式", "大杯", "糖浆", "冰块", sugar="少", milk="燕麦")
# 美式 一杯 大杯
# 加料：('糖浆', '冰块')
# 配置：{'sugar': '少', 'milk': '燕麦'}
```

| 形式 | 含义 |
|------|------|
| `name` | 位置参数（必填） |
| `size="中杯"` | 默认参数 |
| `*toppings` | 收集多余位置参数 → tuple |
| `**options` | 收集多余关键字参数 → dict |

> 💡 顺序口诀：**位置 → 默认 → \*args → \*\*kwargs**，颠倒报错。

### 关键字调用
```python
def power(base, exp):
    return base ** exp

print(power(2, 10))          # 1024
print(power(exp=10, base=2)) # 1024  通过名字传参，顺序无所谓
```

## 3. 作用域：LEGB 规则 🔭

**类比**：找变量像找钥匙 — 先找**自己抽屉**（Local），再找**爸妈抽屉**（Enclosing），再找**家里柜子**（Global），最后找**社区仓库**（Built-in）。

```
L (Local)      函数自己的局部变量
E (Enclosing)  外层函数的变量（嵌套函数）
G (Global)     模块全局
B (Built-in)   print / len / range 这些 Python 自带变量名
```

```python
x = "global"

def outer():
    x = "outer"
    def inner():
        # x = "inner"        # 取消注释会变 inner
        print(x)             # 找不到 inner，往上找 outer
    inner()
outer()                     # outer

# 修改全局：
count = 0
def incr():
    global count
    count += 1
incr()
print(count)                # 1
```

## 4. lambda 匿名函数 ⚡

```python
square = lambda x: x * x
print(square(5))    # 25

# 常和 sort/map/filter 配合
nums = [(1,2),(3,1),(2,5)]
nums.sort(key=lambda t: t[1])
print(nums)         # [(3,1),(1,2),(2,5)]
```

> 💡 lambda 只能写**一行表达式**，复杂逻辑用 def。

## 5. 高阶函数：map / filter / reduce 🚀

```python
nums = [1, 2, 3, 4, 5]

# map：对每个元素做处理
print(list(map(lambda x: x*x, nums)))   # [1, 4, 9, 16, 25]

# filter：过滤
print(list(filter(lambda x: x%2==0, nums)))   # [2, 4]

# reduce：累计
from functools import reduce
print(reduce(lambda a, b: a+b, nums))   # 15

# 但很多时候列表推导式更易读：
print([x*x for x in nums])
print([x for x in nums if x%2==0])
```

| 工具 | 等价推导式 | 何时用 |
|------|-----------|--------|
| `map(f, xs)` | `[f(x) for x in xs]` | 数据流式处理 |
| `filter(f, xs)` | `[x for x in xs if f(x)]` | 同上 |
| `reduce(f, xs)` | 需要 for 循环写 | 聚合（求和、求最大） |

## 7. 模块 import 的 4 种写法 📦

新建两个文件：

```python
# math_utils.py
PI = 3.14159
def add(a, b):
    return a + b
```

```python
# main.py
import math_utils                       # 写法 1：导入整个模块
print(math_utils.add(1, 2))

import math_utils as mu                 # 写法 2：起别名
print(mu.PI)
```

## 10. 文件 IO：with open 📁

```python
# 写
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n第二行\n")

# 读
with open("hello.txt", "r", encoding="utf-8") as f:
    content = f.read()           # 读全部
print(content)

# 按行读（推荐，省内存）
with open("hello.txt", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip())
```

| 模式  | 含义               |
| --- | ---------------- |
| `r` | 读（默认）            |
| `w` | 写（**会清空原文件！**）   |
| `a` | 追加               |
| `b` | 二进制（如 `rb`、`wb`） |
| `x` | 创建（已存在则报错）       |

> 💡 `with` 自动关文件，不会忘 — 强烈推荐永远用 with。

## 11. pathlib：现代化路径处理 🛣️

```python
from pathlib import Path

# 跨平台拼接，Windows 下自动用 \
p = Path("data") / "users.txt"
print(p)                             # data/users.txt

# parents=True 递归创建父目录，exist_ok=True 已存在不报错
p.parent.mkdir(parents=True, exist_ok=True)
p.write_text("hello", encoding="utf-8")
print(p.read_text(encoding="utf-8")) # hello

# suffix 含点扩展名，stem 去后缀文件名
print(p.exists(), p.is_file(), p.suffix, p.stem)
# True True .txt users

# 遍历当前目录下的 .py 文件
for f in Path(".").glob("*.py"):
    print(f.name, f.stat().st_size)
```

## 12. JSON 序列化与反序列化 🔄

**类比**：JSON 像快递员的"打包标准格式"。Python 对象太复杂，存盘 / 联网前需要"打包"成 JSON 字符串。

```python
import json

data = {"name": "李雷", "age": 18, "skills": ["py", "js"]}

# 对象 → 字符串；ensure_ascii=False 保留中文不转义，indent 美化输出
text = json.dumps(data, ensure_ascii=False, indent=2)
print(text)

# 字符串 → 对象
back = json.loads(text)
print(back["skills"][0])      # py

# dump/load 不带 s，直接操作文件对象
with open("user.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

with open("user.json", encoding="utf-8") as f:
    obj = json.load(f)
print(obj)
```

| 方法 | 含义 |
|------|------|
| `dumps` | dump string — 转字符串 |
| `loads` | load string — 从字符串读 |
| `dump`  | dump → file |
| `load`  | load ← file |

## 13. 实战 1：成绩管理系统模块化 🎓

文件结构：
```
score_app/
├── __init__.py
├── storage.py        # 文件读写
└── analyzer.py       # 分析
main.py
```

```python
# score_app/__init__.py
"""成绩记录与统计的小型应用包。"""
```

```python
# score_app/storage.py
"""成绩数据的持久化：负责把数据在内存对象与 JSON 文件之间转换。"""

import json
from pathlib import Path

# 数据文件路径。注意是相对路径，最终位置取决于启动 main.py 时的当前工作目录，
# 而不是本模块所在目录；如需固定位置，可改为 Path(__file__).parent / "scores.json"。
PATH = Path("scores.json")


def load():
    """读取成绩列表。

    文件不存在时返回空列表（首次运行的正常情况），
    其余情况直接返回 JSON 反序列化后的对象（预期为 list[dict]）。
    """
    if not PATH.exists():
        return []
    return json.loads(PATH.read_text(encoding="utf-8"))


def save(data):
    """把成绩列表写入文件。

    参数 data: 可被 json 序列化的对象，通常是 list[dict]。
    ensure_ascii=False 让中文名以原文写入而非 \\uXXXX 转义，便于人工查看。
    该操作为整体覆盖写，不做追加或加锁，并发写入会互相覆盖。
    """
    PATH.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")
```

```python
# score_app/analyzer.py
"""成绩统计：纯计算逻辑，不涉及文件读写，便于单独测试。"""


def average(students, subject):
    """计算所有学生在指定科目上的平均分。

    参数 students: 学生列表，每个元素是形如 {"name": "小明", "math": 90} 的字典。
    参数 subject:  要统计的科目字段名，如 "math"。
    返回:          平均分（float）。

    调用方需保证 students 非空且每项都含有 subject 字段，
    否则会分别触发 ZeroDivisionError 或 KeyError。
    """
    return sum(s[subject] for s in students) / len(students)
```

```python
# main.py
"""入口：追加一条成绩记录并打印数学平均分。"""

from score_app import storage, analyzer

# 1. 读取已有数据（文件不存在时得到空列表）
data = storage.load()

# 2. 追加一条新记录
data.append({"name": "小明", "math": 90})

# 3. 落盘，覆盖写入 scores.json
storage.save(data)

# 4. 基于当前全部数据计算数学平均分
print(analyzer.average(data, "math"))
```

## 14. 实战 2：批量重命名脚本 🔁

```python
from pathlib import Path

# 待处理的图片目录。相对路径，实际位置取决于运行时的工作目录
folder = Path("photos")

# glob("*.jpg") 只匹配当前目录下、扩展名恰好是小写 .jpg 的文件（不递归、不含 .JPG）
# sorted 按文件名的字典序排序，保证每次运行的重命名顺序一致、结果可复现
# enumerate(..., 1) 让编号从 1 开始，而不是默认的 0
for i, f in enumerate(sorted(folder.glob("*.jpg")), 1):
    # :03d 表示至少三位、不足左补零：1 -> "001"，12 -> "012"，1234 -> "1234"
    new = folder / f"photo_{i:03d}.jpg"
    # rename 在同目录内即「改名」；跨目录时等价于移动。
    # 注意：POSIX 上目标已存在会被静默覆盖，Windows 上则抛 FileExistsError
    f.rename(new)
    # 改名后 f 仍指向旧路径，f.name 取到的仍是原名，因此能打印出「原名 → 新名」
    print(f"{f.name} → {new.name}")
```

## 15. 实战 3：JSON 配置文件读写 ⚙️

```python
import json
from pathlib import Path

# 配置文件路径。相对路径，最终位置取决于运行时的工作目录，而非本脚本所在目录；
# 若希望配置固定跟着脚本走，可改为 Path(__file__).parent / "config.json"
CONFIG = Path("config.json")


def load_config():
    """读取配置字典。

    文件存在时返回 JSON 反序列化后的对象（预期为 dict）；
    不存在时返回一份内置默认配置——这是「首次运行」的正常情况，
    而非错误，所以用默认值兜底而不是抛异常。
    """
    if CONFIG.exists():
        return json.loads(CONFIG.read_text(encoding="utf-8"))
    return {"theme": "light", "lang": "zh"}


def save_config(cfg):
    """把配置字典整体覆盖写入文件。

    参数 cfg: 可被 json 序列化的对象，通常是 dict。
    ensure_ascii=False 让中文等非 ASCII 字符以原文写入而非 \\uXXXX 转义，
    indent=2 让文件保持可读，便于人工查看和版本控制 diff。
    注意是整体覆盖写，不会保留文件中原有的、cfg 里没有的键。
    """
    CONFIG.write_text(json.dumps(cfg, ensure_ascii=False, indent=2), encoding="utf-8")


# 读 → 改 → 写：读取当前配置（无文件则为默认值）
cfg = load_config()
# 只改 theme，其余键（如 lang）原样保留
cfg["theme"] = "dark"
save_config(cfg)
print("已保存", cfg)
```

## 16. 实战 4：命令行待办 `cli-todo` 🗒️

这是本章的**主线产出**（对应总纲的 T3），也是后面第 08 篇（用 Pydantic 重写它）和第 09 篇（把它打包发布）要接着改的那个项目。

先把最朴素的版本做出来——**数据就是一个 list of dict**，存成 JSON 文件。后面两章再一步步升级它。

```python
# todo.py —— 用法：
#   python todo.py add "写代码"
#   python todo.py list
#   python todo.py done 1
#   python todo.py remove 2
import json
import sys
from pathlib import Path

DATA = Path("todos.json")


def load():
    """读取全部任务。文件不存在 = 还没有任何任务，这是正常情况。"""
    if not DATA.exists():
        return []
    return json.loads(DATA.read_text(encoding="utf-8"))


def save(tasks):
    """整体覆盖写入。ensure_ascii=False 让中文原样保存。"""
    DATA.write_text(json.dumps(tasks, ensure_ascii=False, indent=2), encoding="utf-8")


def add(tasks, title):
    """追加一条任务。id 用「当前最大 id + 1」，空列表时第一个 id 是 1。"""
    new_id = max((t["id"] for t in tasks), default=0) + 1
    tasks.append({"id": new_id, "title": title, "status": "todo"})
    return new_id


def cmd_list(tasks):
    if not tasks:
        print("还没有任务，先用 add 加一条：python todo.py add \"写代码\"")
        return
    for t in tasks:
        mark = "x" if t["status"] == "done" else " "
        print(f"[{mark}] {t['id']}. {t['title']}")


def cmd_done(tasks, tid):
    """按 id 标记完成。没找到就抛 ValueError，由 main 统一转成友好提示。"""
    for t in tasks:
        if t["id"] == tid:
            t["status"] = "done"
            return
    raise ValueError(f"没有 id={tid} 的任务")


def cmd_remove(tasks, tid):
    """按 id 删除。用新列表重建 —— 不能在遍历时改原列表。"""
    remaining = [t for t in tasks if t["id"] != tid]
    if len(remaining) == len(tasks):
        raise ValueError(f"没有 id={tid} 的任务")
    return remaining


def main(argv):
    if len(argv) < 2:
        print("用法：python todo.py <add|list|done|remove> [参数]")
        return 1

    action, tasks = argv[1], load()

    if action == "add":
        if len(argv) < 3:
            print("用法：python todo.py add \"任务内容\"")
            return 1
        new_id = add(tasks, argv[2])
        save(tasks)
        print(f"已添加 #{new_id}: {argv[2]}")
    elif action == "list":
        cmd_list(tasks)
    elif action == "done":
        if len(argv) < 3:
            print("用法：python todo.py done <id>")
            return 1
        try:
            cmd_done(tasks, int(argv[2]))
        except ValueError as e:
            print(e)
            return 1
        save(tasks)
        print(f"已完成 #{argv[2]}")
    elif action == "remove":
        if len(argv) < 3:
            print("用法：python todo.py remove <id>")
            return 1
        try:
            tasks = cmd_remove(tasks, int(argv[2]))
        except ValueError as e:
            print(e)
            return 1
        save(tasks)
        print(f"已删除 #{argv[2]}")
    else:
        print(f"未知命令：{action}")
        return 1
    return 0


if __name__ == "__main__":
    # sys.argv[0] 是脚本名，命令从 argv[1] 开始。
    sys.exit(main(sys.argv))
```

**为什么这样写**：

- **存 JSON 而不是存 pickle**——JSON 人能直接看懂、能 diff、能手动改，代价是只能存字符串/数字这类基本类型（够这个项目用了）。
- **函数返回错误信息而不是直接 `sys.exit()`**——`cmd_done` 抛 `ValueError`、由 `main` 捕获并打印，函数本身保持纯粹、好测。第 08 篇正是从这一点切入：抛自定义异常 + Pydantic 校验。
- **整体覆盖写**——`save` 直接覆盖 `todos.json`。写到一半崩溃会损坏文件，生产项目要改成"写临时文件再原子替换"，这里先记住这个坑。
- **id 策略**——`max(id) + 1`。删掉中间的任务后，新任务的 id 不会复用旧 id，所以第 08 篇里那句"有删除功能时 id 会重用"的注释也留个心眼。

> 🎯 **交付标准**：4 个命令全部可用；数据落在 `todos.json`；代码分成函数、每行不超过 79 字符（PEP 8）。

## 🐛 常见错误集合

| `UnboundLocalError`   | 函数里又读又写全局变量没声明 `global`       |
| `ModuleNotFoundError` | 没装 / 没在虚拟环境 / 路径不对            |
| `JSONDecodeError`     | JSON 格式错了（如尾逗号、单引号）           |
| 默认参数 `=[]` 坑          | 用 `=None` 然后函数里设默认            |
| 文件中文乱码                | `open(..., encoding="utf-8")` |
| 遍历列表时删除元素              | 用新列表重建（`[t for t in ... if ...]`），别在循环里 `del` |
| `json.load` 报 `JSONDecodeError` | 文件写坏了 —— 写入要用"临时文件 + 原子替换" |
| 脚本参数读不到                | `sys.argv[0]` 是脚本名，命令从 `sys.argv[1]` 开始 |
