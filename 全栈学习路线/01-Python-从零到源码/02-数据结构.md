## 1. 列表 list：会变长的购物车 🛒

**类比**：list 就像超市购物车 — 你能往里**塞**商品、**拿走**商品、**调换**商品的位置，整个购物车能装很多东西。

### 1.1 创建与索引
```python
fruits = ["苹果", "香蕉", "橘子"]
print(fruits[0])    # 苹果   下标从 0 开始
print(fruits[-1])   # 橘子   倒数第一
print(len(fruits))  # 3      长度
```

### 1.2 切片（同字符串）
```python
nums = [10, 20, 30, 40, 50]
print(nums[1:4])    # [20, 30, 40]
print(nums[::-1])   # [50, 40, 30, 20, 10]  反转
```

### 1.3 增删改查
```python
fruits = ["苹果", "香蕉"]

# 增
fruits.append("橘子")          # 末尾追加 → ['苹果','香蕉','橘子']
fruits.insert(1, "葡萄")       # 在下标 1 插入 → ['苹果','葡萄','香蕉','橘子']
fruits.extend(["梨","桃"])     # 追加多个

# 删
fruits.remove("香蕉")          # 按值删除（删第一个匹配的）
last = fruits.pop()           # 弹出最后一个并返回
del fruits[0]                 # 按下标删

# 改
fruits[0] = "西瓜"

# 查
print("西瓜" in fruits)        # True / False
print(fruits.index("梨"))      # 返回下标
print(fruits.count("梨"))      # 出现次数
```

### 1.4 列表推导式（Pythonic 利器）⭐
```python
# 普通写法
squares = []
for i in range(1, 6):
    squares.append(i * i)
# 推导式写法（一行搞定）
squares = [i * i for i in range(1, 6)]
print(squares)   # [1, 4, 9, 16, 25]

# 带筛选
evens = [i for i in range(20) if i % 2 == 0]
print(evens)     # [0, 2, 4, ..., 18]

# 双层循环
pairs = [(x, y) for x in [1,2] for y in [3,4]]
print(pairs)     # [(1,3),(1,4),(2,3),(2,4)]
```

> 💡 **划重点**：列表推导式 = `[表达式 for 元素 in 可迭代对象 if 条件]`，比 for 循环更短更快。

## 2. 元组 tuple：一旦决定就不能改的清单 🔒

**类比**：tuple 就像**已经打印出来的发票** — 上面的内容不能再改了。

```python
point = (3, 4)
print(point[0], point[1])  # 3 4

# point[0] = 10   # ❌ 报错 TypeError

# 解包（很常用！）
x, y = point
print(x, y)        # 3 4

# 一行交换两个变量
a, b = 1, 2
a, b = b, a
print(a, b)        # 2 1
```

### namedtuple：给位置起名字
```python
from collections import namedtuple
Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)
print(p.x, p.y)    # 3 4  — 比 p[0] / p[1] 易读
```

> 💡 何时用 tuple？— **数据不变**且**位置有意义**（比如坐标、日期）的时候。

## 3. 字典 dict：键值对档案柜 🗄️

**类比**：dict 就像**字典书** — 通过"词条"（键）查"释义"（值），查找极快。

### 3.1 基本用法
```python
person = {"name": "李雷", "age": 18, "city": "北京"}

print(person["name"])              # 李雷
person["age"] = 19                 # 修改
person["job"] = "学生"             # 新增
del person["city"]                 # 删除

print("name" in person)            # True
```

### 3.2 安全的查找：get / setdefault
```python
score = {"小明": 90}

print(score["小红"])                  # ❌ KeyError
print(score.get("小红"))              # None  键不存在时返回 None
print(score.get("小红", 0))           # 0     给个默认值

# setdefault: 没有就设上，有就返回
score.setdefault("小红", 60)
print(score)                         # {'小明': 90, '小红': 60}
```

### 3.3 遍历
```python
person = {"name": "李雷", "age": 18}

for key in person:                   # 默认遍历键
    print(key)

for key, value in person.items():    # 同时拿键值
    print(key, "=", value)

print(list(person.keys()))           # ['name', 'age']
print(list(person.values()))         # ['李雷', 18]
```

### 3.4 字典推导式
```python
nums = [1, 2, 3, 4]
square_map = {n: n*n for n in nums}
print(square_map)   # {1:1, 2:4, 3:9, 4:16}
```

### 3.5 三个"加强版字典"：defaultdict / Counter / OrderedDict

普通 dict 访问不存在的键会 `KeyError`，计数要写 `freq.get(word, 0) + 1`——`collections` 把这两个高频动作都替你做了：

```python
from collections import defaultdict, Counter, OrderedDict

# defaultdict：给字典一个"缺键工厂"，第一次访问自动造默认值
groups = defaultdict(list)              # 工厂是 list → 缺键时值是 []
for name in ["Alice", "Bob", "Amy"]:
    groups[name[0]].append(name)        # 不用先判断 'A' 在不在
print(dict(groups))   # {'A': ['Alice', 'Amy'], 'B': ['Bob']}

# Counter：专门的计数器（练习 2 的词频统计一行搞定）
print(Counter("mississippi").most_common(2))   # [('i', 4), ('s', 4)]

# OrderedDict：记住插入顺序的 dict。
# ⚠️ Python 3.7+ 普通 dict 本身就保序，OrderedDict 的剩余价值只有两点：
#    1) move_to_end() / popitem(last=False) —— 手写 LRU 缓存要用；
#    2) 相等比较看顺序 —— dict 里 {'a':1,'b':2} == {'b':2,'a':1} 为 True，
#       OrderedDict 里为 False。
od = OrderedDict([("x", 1), ("y", 2)])
od.move_to_end("x")
print(list(od))     # ['y', 'x']
```

> 💡 **选型**：分组/累加 → defaultdict；统计频次 → Counter；LRU 缓存 → OrderedDict（或直接用 `functools.lru_cache`）。日常 99% 的场景普通 dict 就够，别为用而用。

### 🎯 练习 2：词频统计
统计句子 `"the quick brown fox jumps over the lazy dog the end"` 里每个单词出现的次数。

<details>
<summary>答案</summary>

```python
sentence = "the quick brown fox jumps over the lazy dog the end"
freq = {}
for word in sentence.split():
    freq[word] = freq.get(word, 0) + 1
print(freq)
# {'the': 3, 'quick': 1, 'brown': 1, ...}
```
</details>

## 4. 集合 set：天生去重 🪣

**类比**：set 就像一个**没有重复客人的会员名单** — 同一个人加入多次只算一次。

```python
nums = [1, 1, 2, 3, 3, 4]
unique = set(nums)
print(unique)       # {1, 2, 3, 4}

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)        # 并集 {1, 2, 3, 4, 5, 6}
print(a & b)        # 交集 {3, 4}
print(a - b)        # 差集 {1, 2}
print(a ^ b)        # 对称差 {1, 2, 5, 6}

# 增删
a.add(10)
a.discard(1)        # 不存在不报错
a.remove(2)         # 不存在会报错
```

### frozenset：不可变集合
```python
fs = frozenset([1, 2, 3])
# fs.add(4)   # ❌ 不能改
# 可以作为 dict 的键、放进 set 里
```

## 5. 字符串高级：编码与正则 🔍

### 5.1 编码：str 与 bytes 的来回 🔁

**类比**：`str` 是你脑子里的"意思"，`bytes` 是电报机敲出去的"点划"。**存盘、走网络的都是 bytes**，Python 内存里才是 str——中间隔一次编码/解码。

```python
s = "中文"

b = s.encode("utf-8")      # str → bytes：编码
print(b)                   # b'\xe4\xb8\xad\xe6\x96\x87'（6 个字节，中文每个 3 字节）
print(len(s), len(b))      # 2 6 —— 字符数 ≠ 字节数！

back = b.decode("utf-8")   # bytes → str：解码
print(back == s)           # True

# 编解码必须用同一套编码，否则乱码/报错：
try:
    "中文".encode("utf-8").decode("gbk")
except UnicodeDecodeError as e:
    print("炸了：", e)      # 'gbk' codec can't decode byte 0xe4 ...
```

> ⚠️ **三条铁律**（第 03 篇文件 IO 会再撞见）：
> 1. 读写文本文件永远显式 `encoding="utf-8"`——Windows 默认 GBK，同一份文件换台机器就乱码；
> 2. 网络/文件收到的是 bytes，**先 decode 成 str 再处理**，别拿 bytes 做字符串操作；
> 3. `len()` 数的是字符不是字节；要字节数用 `len(s.encode("utf-8"))`（按字节截断多语言文本是事故高发区）。

### 5.2 正则 re 入门

**类比**：正则就像**搜索通配符** — 你描述"我要找的样子"，Python 帮你找出所有匹配的部分。

```python
import re

text = "我的电话是 13800138000，他的电话是 13912345678"
phones = re.findall(r"1[3-9]\d{9}", text)
print(phones)   # ['13800138000', '13912345678']

# 常用元字符
# \d  数字  \w 字母数字下划线  \s 空白
# .   任意字符
# +   1 个或多个   *  0 个或多个   ? 0 或 1
# {n} 恰好 n 个    {n,m} n 到 m 个

# 替换
print(re.sub(r"\d", "*", "abc123"))   # abc***
```

> 💡 正则练习神器：https://regex101.com/ （切到 Python 模式）

## 7. 内存视角：可变 vs 不可变 🧠

**类比**：
- **不可变**（int/str/tuple）→ 像便利贴上写好的字，要改就**贴一张新的**。
- **可变**（list/dict/set）→ 像白板，**能擦掉重写**。

```python
# 不可变：改了 = 创建新对象
a = "hello"
print(id(a))     # 比如 4400000000
a = a + " world"
print(id(a))     # id 变了！其实是新对象

# 可变：原地修改，id 不变
lst = [1, 2, 3]
print(id(lst))   # 比如 4500000000
lst.append(4)
print(id(lst))   # 还是 4500000000

# 默认参数只要是"可变对象"（list / dict / set / 自定义可变类实例），就一定有坑。
def add(item, target=[]):     # ❌ 危险
    target.append(item)
    return target

print(add(1))   # [1]
print(add(2))   # [1, 2]  — 共享了同一个列表！
```

> 💡 **划重点**：**默认值在定义时绑定一次、所有调用共享 → 可变默认值会"记住"上次的修改**。用 `None` 哨兵 + 函数体内创建，是这个坑的标准解法。

## 8. 实战 1：词频统计（升级版）📊

```python
import re
from collections import Counter
text = """
Python is great Python is easy Python is fun
We love Python because Python makes life easy
"""
# \w+ 匹配"单词字符"：在 Unicode 模式下包含字母、数字、下划线，
# 也会匹配中文/其他 Unicode 字母。纯英文统计建议改成 [a-z]+（见下方"改进"）
# .lower() 先统一大小写，否则 Python/python 会被算成两个词
words = re.findall(r"\w+", text.lower())
# Counter 是 dict 子类：词 → 出现次数
counter = Counter(words)
# most_common(3) 按计数降序取前 3；
# 计数相同时按"首次出现顺序"（内部是稳定排序），结果可复现
print(counter.most_common(3)) # [('python', 4), ('is', 3), ('easy', 2)]
```

## 9. 实战 2：学生成绩管理 🎓

```python
from dataclasses import dataclass, field   # field 当前未使用，可删

@dataclass
class Student:
    name: str
    math: int
    en: int

    @property
    def avg(self) -> float:
        # 用 property 而非在 __init__ 里算好存成字段：
        # math/en 一旦被修改，avg 会自动跟着变，不会出现"数据改了、平均分还是旧的"
        return (self.math + self.en) / 2


# 模块级可变状态：仅适合单文件小脚本；生产代码应改为类/函数参数，便于测试和复用
students: list[Student] = []   # 需 Python 3.9+，3.8 及以下写 List[Student]


def add_student(name: str, math: int, en: int) -> None:
    # 查重：any() 是 O(n) 线性扫描，学生数上万时整体插入会退化为 O(n²)，
    # 届时改用 set/dict 维护已存在名字
    if any(s.name == name for s in students):
        raise ValueError(f"学生已存在: {name}")
    students.append(Student(name, math, en))


add_student("小明", 90, 85)
add_student("小红", 78, 92)
add_student("小刚", 65, 70)

# 按派生属性 avg 排序：property 可以直接当作 key 使用
students.sort(key=lambda s: s.avg, reverse=True)

for s in students:
    # :>4 按"字符数"补空格，不按显示宽度；中文占 2 列，
    # 名字都是 2 字时恰好对齐，混入 4 字名字会错位（需要 unicodedata 修正）
    print(f"{s.name:>4}  数学{s.math}  英语{s.en}  平均{s.avg:.1f}")
```

## 10. 实战 3：ASCII 词云 ☁️

```python
from collections import Counter
text = "apple banana apple orange banana apple apple orange grape"
# split() 按任意空白切分，不处理标点：
# "apple," 会变成独立词 "apple,"，需要处理标点就用 re.findall(r"[a-z]+", text.lower())
counter = Counter(text.split())
# 无参 most_common() = 按计数降序返回全部 (词, 次数)
# 同计数时保持"首次出现顺序"（内部 sorted 是稳定排序，reverse 不改变同组相对顺序）
for word, n in counter.most_common():
    # <8 左对齐到宽度 8，让后面的条形起点对齐；英文按字符数补空格没有中文宽度问题
    print(f"{word:<8} {'#' * n}  ({n})")
```
**运行结果**：
```
apple    ####  (4)
banana   ##  (2)
orange   ##  (2)
grape    #  (1)
```

## 🐛 常见错误集合

| 错误                                   | 原因                                            |
| ------------------------------------ | --------------------------------------------- |
| `KeyError`                           | 字典访问了不存在的键 → 用 `.get()`                       |
| `IndexError`                         | 列表越界 → 检查 `len()`或少用下标                        |
| `TypeError: unhashable type: 'list'` | list 不能当 dict 的键 → 用 tuple                    |
| 默认参数共享                               | 别用 `def f(x=[])`                              |
| 修改列表时遍历                              | 在遍历中 `lst.remove()` 会跳元素，，`append` 会死循环，先复制再改 |
