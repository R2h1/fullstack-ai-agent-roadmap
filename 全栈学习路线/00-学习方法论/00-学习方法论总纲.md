# 第 00 章 · 学习方法论（2-3 周）

> 这是整条路线的**第 0 章**，也是唯一一章不讲技术的章。
> **没读完这一章不要进 [[全栈学习路线/01-Python-从零到源码/00-Python总纲]]。**
>
> 后面 9 章教的是"怎么写"，这一章教的是"怎么学"。学得慢、写着写着就放弃、三个月后什么都没留下——90% 的问题出在这一章，而不是技术难度上。

## 🎯 章节目标

学完本章你将：

- 有一套自己的**学习节奏与反馈系统**（不是靠意志力硬撑）
- 装好一套**能立刻开工**的开发环境（Python / Node / Git / VS Code / 终端）
- 掌握 **Git + GitHub 全流程**，包括提交、撤销、回滚、提 PR
- 会用 **AI 当老师而不是保姆**：会提问、会追问、会验收
- 有一套**能长期沉淀**的笔记系统（Obsidian + 费曼学习法 + 双向链接）
- 知道**怎么读别人的代码**，以及从哪个量级的项目开始最合适
- 拥有自己的 **学习仪表盘**（HTML 进度页）和**学习契约**
- 建立了**元能力复查机制**（每学完一章回来看一次进度和笔记，否则前面 4 条会在 12 个月里自然衰减）

## 📖 详细内容大纲

### 第 01 篇 · 如何高效学习编程

- **1. 你为什么学不会**：教程地狱 / 复制粘贴幻觉 / AI 依赖症 三个陷阱与对应解药
- **2. 学习循环**：读 → 仿 → 关掉教程默写 → 改造 → 写笔记教别人 → 一周后回顾
- **3. 时间安排**：每天 3 小时底线；工作日怎么切、周末怎么排、GitHub 绿点为什么重要
- **4. 环境配置速查**：macOS/Linux 与 Windows(WSL2) 两套命令清单
- **5. Git/GitHub 必会 10 命令**：够用就行，细节留给第 03 篇
- **6. 怎么用 AI 当老师**：好提问 vs 坏提问对比、3 条铁律、15 分钟原则
- **7. 反馈系统**：每天 / 每周 / 每月 / 每章 四个周期的固定动作
- **📝 考核任务**：5 项（含人生第一个 PR、《我的学习契约》、Norvig 读后感）
- **🚀 章节项目**：学习仪表盘（纯 HTML+CSS+JS → GitHub Pages）

### 第 02 篇 · 环境配置完全指南

- macOS：Homebrew → iTerm2 → Oh My Zsh → Python(uv) → Node(nvm) → pnpm → VS Code
- Windows：为什么强烈建议 WSL2 + Ubuntu，`wsl --install` 全流程
- **终极自我检查**：一条命令确认工具链真的就位
- 🐛 常见错误：8 条速查（`command not found` / `permission denied` / Homebrew 巨慢 / WSL 打不开 / jammy 上 gh 版本过旧 …）

### 第 03 篇 · Git 与 GitHub 入门

- 版本控制的三个类比：游戏存档 / 后悔药 / 时光机
- **四大区域模型**：工作区 → 暂存区 → 本地仓库 → 远程仓库
- **核心 10 命令场景手册**：每条都给"什么时候用"，不是命令清单
- **后悔药 4 命令**：`git restore` / `git reset` / `git revert` / `git reflog`（没 push 用 reset，已 push 用 revert）
- SSH key 配置 + `gh` CLI 登录 + **第一个 PR 实战 6 步**
- 约定式提交规范（Conventional Commits）
- 🐛 常见错误：12 条速查（含 merge conflict / detached HEAD / rejected / 误提交密钥）

### 第 04 篇 · 命令行终端基础

- 文件系统树 + `~ / . ..` 特殊符号
- **28 个核心命令（45 条用法）**分组：导航 / 文件 / 查看 / 搜索 / 权限 / 进程 / 网络 / 压缩
- 管道 `|`、重定向 `>` `>>`、环境变量与 PATH、`~/.zshrc` 配置
- 13 个必须形成肌肉记忆的快捷键
- **本篇实战**：做一个纯命令行小工具 `note.sh`（`date` + `>>` + `$1` + `chmod +x`）
- 🐛 常见错误：13 条速查（含 `rm -rf` 误删、`kill -9`、乱码、tar 格式不匹配）

### 第 05 篇 · VSCode 与 AI 辅助编程

- 界面五大区域 + 15 个必装插件
- **20 个必会快捷键**（mac / win 双栏对照）
- 调试器三大概念 + 六步调试流程
- AI 工具选型表（Claude Code / Cursor / Continue / Copilot）
- **防 AI 依赖症**：15 分钟原则 + 3 个做法 + 3 个自检问题
- 提问模板：角色 + 背景 + 问题 + 约束 + 期望输出
- 🐛 常见错误：10 条速查（含 CRLF 换行、终端 shell 选错、插件拖慢启动）

### 第 06 篇 · GitHub 项目精选 · 入门导航

- 🌟 第一批必 fork：8 个地基级仓库（freeCodeCamp、developer-roadmap、build-your-own-x …）
- 🎯 Easy-vibe 类：6 个 30 分钟能跑起来的（微软 *-for-beginners、Claude Cookbook、OpenAI Cookbook）
- 📚 中文向导：7 个（free-programming-books-zh_CN、cs-self-learning、datawhalechina ×3、CS-Notes、advanced-java）
- 🛠️ Git / GitHub / 工具类：3 个仓库（github/docs、github/gitignore、Conventional Commits）+ 2 个站点（GitHub Skills、gitignore.io）
- 💡 用 GitHub 学习的 7 个技巧 + ✅ 本篇实战：fork 2 个仓库并改一行 push 上去
- 🐛 常见错误：8 个学习者陷阱（Star 上瘾、资源囤积、教程地狱、盯巨型项目 …）

### 第 07 篇 · 费曼学习法与笔记系统

- 费曼 4 步 + 为什么它对编程特别有效
- Obsidian **四大笔记类型** + 两级标签体系 + 双向链接 + MOC + 知识图谱
- **两遍法则**：24 小时内重写，一周后回看
- 卡片笔记法（Zettelkasten）3 条原则 + 5 步工作流
- 番茄工作法（6 番茄输入 + 2 番茄输出）
- 插件清单：Templater / Dataview / Excalidraw / Tasks / Calendar / Spaced Repetition
- 🐛 常见错误：10 条速查（只摘抄不重构、标签失控、笔记写太长、Templater 语法写错 …）

### 第 08 篇 · 反向工程别人的代码

- 为什么读源码比看教程更快，以及它的边界
- **选项目的 5 条标准** + 2 条要避开的雷
- **7 步法**：README → demo → 依赖清单 → entry point → 依赖图 → 最小功能流 → 加注释写博客
- 用工具量化项目：`cloc` / `git shortlog -sn` / `git log -p --follow`
- 流读 vs 模块读、标注阅读法、看 PR / Issue 的 URL 查询语法
- **推荐 5 个第一次读的项目**（按真实核心源码行数递增：micrograd 154 行 → zustand 1.7k → starlette 3.7k → hono 5k → datasette 11k）
- 🐛 常见错误：11 条速查（硬啃大项目、被测试文档淹没、版本对不上、改不动别人代码 …）

前面 8 项都是**单篇产出**，这一项是**唯一需要你把它们串起来**的任务：

## 🚀 章节大项目：学习仪表盘

### 需求

做一个纯 HTML + CSS + 原生 JS 的学习进度页，部署到 GitHub Pages。

### 技术栈

- HTML5 + CSS3 + 原生 JS（不用任何框架）
- 部署到 GitHub Pages

### 验收标准

- [ ] 展示 10 个章节列表 + 进度条
- [ ] 点击章节能展开看任务清单
- [ ] 进度数据存在 `localStorage`，刷新不丢
- [ ] 已部署到 GitHub Pages，能用 URL 访问
- [ ] commit 信息符合约定式提交规范

### 进阶挑战

- 改成 PWA，支持离线访问
- 用 GitHub Actions 自动同步 commit 频次到首页

### 🔁 元能力复查节点（每学完一章回来看一次）

00 章教的四样东西 —— **学习节奏、笔记系统、AI 当老师、学习契约** —— 是元能力，不复习就会衰减。本章的产出物是仪表盘，所以**仪表盘不只是进度条，它是你 12 个月的复习入口**：

| 什么时候 | 花 5 分钟做什么 | 在哪看 |
|---------|----------------|--------|
| 每学完一章 | 更新进度 + 写下"这章我真正会的是 ___ / 还不会的是 ___" | 仪表盘 + 周报模板 |
| 每月最后一个周日 | 翻一遍 Atomic Note，删掉 1/3，补充剩下的 | 仪表盘 + Obsidian |
| 每季度 | 重读《我的学习契约》，检查奖惩机制还合不合理 | `_我的进度追踪/学习契约` |

> 📌 **这是 00 章唯一一件"不做就会消失"的事。** 环境装一次就一直在，Git 学会了忘不掉；但"每天 3 小时 + 每周一篇周报"这种承诺，三个月不复习就等于没做过。

> **现在做不出来很正常**——学完全书第 02 章《JavaScript 从零到源码》和第 03 章《HTML-CSS 现代 Web》再回来重做，会有恍然大悟的感觉。先做最简版（哪怕丑），重点是走通"写代码 → push → 部署 → 公网访问"全流程。
